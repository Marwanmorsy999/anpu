1. Open https://github.com/Marwanmorsy999/anpu
2. Click the gear icon next to **About** (top-right of the code view).
3. Paste **Description** and **Topics** below, check
   **Releases**, and save.

## Notes

- Topics are lowercase, hyphenated, and must already exist on GitHub
  or they will be created on save. All 10 above are existing popular topics.
- Keep the positioning honest: "the scanner that's honest about what it
  can't prove." Do not add topics for capabilities ANPU doesn't have
  (e.g., no `exploitation`, no `c2`, no `osint-automation`).
- Social preview image (`anpu-og.png` in repo root) can be set under
  **Settings → General → Social preview → Upload image**.
